# Memory Game

## Descripción

Este repositorio contiene una versión modificada del juego Memory desarrollado con Python y FreeGames.

## Cambios realizados

. Agregamos un contador de taps (clics).
. Agregamos un detector cuando todas las tarjetas han sido descubiertas.
. Se centró el contenido mostrado dentro de cada tarjeta.
. Se reemplazaron los números por símbolos visuales para facilitar la memorización de las parejas.
